# simulation-predateur-proie

**FR** — Simulation d'un écosystème **prédateur / proie** développée en **Processing** : des proies et des prédateurs évoluent, se déplacent, se reproduisent et meurent selon des règles simples, illustrant une dynamique de populations.

**EN** — A **predator / prey** ecosystem simulation built in **Processing**: prey and predators move, reproduce and die according to simple rules, illustrating population dynamics.

---

## Concepts / Highlights

- **FR**
  - Modélisation orientée objet : classe de base `GraphicObject`, puis `Proie` et `Predateur`.
  - Boucle de simulation temps réel (déplacement, reproduction, prédation).
- **EN**
  - Object-oriented modeling: a `GraphicObject` base class, then `Proie` (prey) and `Predateur` (predator).
  - Real-time simulation loop (movement, reproduction, predation).

## Stack

Processing (Java).

## Lancement / Run

**FR** : ouvrir `labo11111.pde` dans l'IDE **Processing**, puis cliquer sur **Run**.
**EN**: open `labo11111.pde` in the **Processing** IDE, then click **Run**.
